# Glow & Glam Salon – Salon Management Website  

This project is a Salon Management Website.  

The website is created to showcase salon services, pricing, gallery, and contact details with a premium and elegant user interface.

## 📌 Project Objective

The objective of this task was to:

- Design a professional salon website
- Maintain a consistent luxury theme
- Structure service categories clearly
- Implement proper visual hierarchy
- Create an engaging user experience

## 🎨 Design Theme

-  Primary Color: Black
-  Accent Color: Gold
-  Text: White
-  Layout: Desktop Scroll Website
-  Style: Elegant & Luxury Branding

The black & gold theme represents sophistication and premium beauty services.
